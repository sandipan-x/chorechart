# ChoreChart

Make a printable weekly chore chart for your kids: add ages, pick age-appropriate chores, assign days of the week, and print it. Free maker.

## Features
- Kid profiles with names and ages driving the suggestions
- Age-banded chore suggestions (3–5, 6–8, 9–12, 13+) you toggle per child
- Weekly Mon–Sun grid with day assignment and one-click printing
